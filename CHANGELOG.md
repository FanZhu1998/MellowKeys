# Changelog

## 1.0.0

- Portable Windows desktop build with offline piano, notation, fonts and local SQLite saves.
- Shared web/desktop modules, explicit workspace versioning and migration checks.
- Nine musical worlds, forty-five original progression families, four through eight chords, and brake-chord treatments.
- Saved favorites, score arrangement, exact-voicing notation, PDF and MusicXML exports.
- Final polish: keyboard focus preservation, immediate score-title updates, stable-ID renames, request timeouts, recoverable font loading and consistent dark controls.
- Secret scanning, isolated desktop renderer, constrained asset serving, validated saved IDs and a clean source-export workflow.
